# Правила репозитория

- Имя скрипта содержит версию: `Audit-Evtx-<major>.<minor>.ps1` (например, `Audit-Evtx-11.1.ps1`).
  При каждом изменении скрипта повышайте версию и переименовывайте файл (`git mv`), обновляя:
  `$script:Version` и `public const string Version` (C#-ядро) — `<major>.<minor>.0`,
  примеры запуска в справке скрипта, README (имя файла, строка SelfTest, «История»).
- Отвечать пользователю на русском.
